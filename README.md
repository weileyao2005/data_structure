# 数据结构刷题工具

一个纯终端交互的**数据结构选择题练习工具**，用于辅助 PTA 题库刷题和错题复习。

## 核心功能

### 题库管理
- 按章节/PTA 练习集组织题目，每个练习集独立存储
- 每题包含题目描述、A/B/C/D 四个选项、正确答案
- 支持导入和手动录入题目

### 刷题模式
- **手动勾选练习集**：自由选择本次要练习的 PTA 题目集
- **题目分配**：指定总题数（如 40 道），系统按各练习集的题目数量比例随机抽取，尽量平均分配；某集合题量不足时自动从其他集合补足
- **打乱/顺序**：可选择打乱题目顺序或保持原有顺序
- **选项随机化**：每次练习时选项顺序不固定（正确答案不只是 A/B/C/D），避免机械记忆

### 错题本
- 记录每道错题及**错误次数**
- 错题本中的题目和选项均可**复制**，方便粘贴给 AI 进行分析
- 支持按错误次数排序，优先复习高频错题

### 终端交互
- 纯 CLI 界面，无 GUI 依赖
- 清晰的菜单导航和答题反馈
- 答题后即时显示对错和正确答案
