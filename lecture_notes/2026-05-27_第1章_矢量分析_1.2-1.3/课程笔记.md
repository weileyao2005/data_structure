## 1.2 三种常用的正交曲线坐标系

### 为什么需要三种坐标系？

不同的问题具有不同的**对称性**。选择合适的坐标系，可以让问题的数学描述大大简化：

| 对称性 | 最佳坐标系 |
|--------|------------|
| 平面对称（如矩形波导） | 直角坐标系 |
| 轴对称（如无限长导线、同轴电缆） | 圆柱坐标系 |
| 球对称（如点电荷、带电球体） | 球坐标系 |



### 1.2.1 直角坐标系

| 项目 | 内容 |
|------|------|
| 坐标范围 | $-\infty < x,y,z < \infty$ |
| 单位矢量 | $\mathbf{e}_x, \mathbf{e}_y, \mathbf{e}_z$（全部是常矢量） |
| 位置矢量 | $\mathbf{r} = x\mathbf{e}_x + y\mathbf{e}_y + z\mathbf{e}_z$ |
| 长度元 | $\mathrm{d}l_x = \mathrm{d}x,\ \mathrm{d}l_y = \mathrm{d}y,\ \mathrm{d}l_z = \mathrm{d}z$ |
| 度量系数 | $h_x = 1,\ h_y = 1,\ h_z = 1$ |
| 体积元 | $\mathrm{d}V = \mathrm{d}x\,\mathrm{d}y\,\mathrm{d}z$ |

### 1.2.2 圆柱坐标系

| 项目 | 内容 |
|------|------|
| 坐标范围 | $0 \le \rho < \infty,\ 0 \le \phi \le 2\pi,\ -\infty < z < \infty$ |
| 变换关系 | $x = \rho\cos\phi,\ y = \rho\sin\phi,\ z = z$ |
| 单位矢量 | $\mathbf{e}_\rho, \mathbf{e}_\phi, \mathbf{e}_z$（**$\mathbf{e}_\rho, \mathbf{e}_\phi$ 不是常矢量！**） |
| 位置矢量 | $\mathbf{r} = \rho\mathbf{e}_\rho + z\mathbf{e}_z$ |
| 长度元 | $\mathrm{d}l_\rho = \mathrm{d}\rho,\ \mathrm{d}l_\phi = \rho\,\mathrm{d}\phi,\ \mathrm{d}l_z = \mathrm{d}z$ |
| 度量系数 | $h_\rho = 1,\ h_\phi = \rho,\ h_z = 1$ |
| 体积元 | $\mathrm{d}V = \rho\,\mathrm{d}\rho\,\mathrm{d}\phi\,\mathrm{d}z$ |

### 1.2.3 球坐标系

| 项目 | 内容 |
|------|------|
| 坐标范围 | $0 \le r < \infty,\ 0 \le \theta \le \pi,\ 0 \le \phi \le 2\pi$ |
| 变换关系 | $x = r\sin\theta\cos\phi,\ y = r\sin\theta\sin\phi,\ z = r\cos\theta$ |
| 单位矢量 | $\mathbf{e}_r, \mathbf{e}_\theta, \mathbf{e}_\phi$（**全部不是常矢量！**） |
| 位置矢量 | $\mathbf{r} = r\mathbf{e}_r$ |
| 长度元 | $\mathrm{d}l_r = \mathrm{d}r,\ \mathrm{d}l_\theta = r\,\mathrm{d}\theta,\ \mathrm{d}l_\phi = r\sin\theta\,\mathrm{d}\phi$ |
| 度量系数 | $h_r = 1,\ h_\theta = r,\ h_\phi = r\sin\theta$ |
| 体积元 | $\mathrm{d}V = r^2\sin\theta\,\mathrm{d}r\,\mathrm{d}\theta\,\mathrm{d}\phi$ |

### 1.2.4 重要注意事项

> **关键点**：圆柱坐标系中的 $\mathbf{e}_\rho$ 和 $\mathbf{e}_\phi$、球坐标系中的 $\mathbf{e}_r, \mathbf{e}_\theta, \mathbf{e}_\phi$ 都是**随着位置变化而变化的**，不是常矢量！

这意味着：
- **不同位置的两个矢量不能直接用分量加减**（需要先变换到直角坐标系）
- 单位矢量对坐标的偏导数不为零：
  - 圆柱坐标：$\dfrac{\partial\mathbf{e}_\rho}{\partial\phi} = \mathbf{e}_\phi,\quad \dfrac{\partial\mathbf{e}_\phi}{\partial\phi} = -\mathbf{e}_\rho$
  - 球坐标：$\dfrac{\partial\mathbf{e}_r}{\partial\theta} = \mathbf{e}_\theta,\quad \dfrac{\partial\mathbf{e}_r}{\partial\phi} = \mathbf{e}_\phi\sin\theta$ 等

**度量系数（拉梅系数）** $h_i = \dfrac{\mathrm{d}l_i}{\mathrm{d}q_i}$ 是连接坐标微分和实际长度的关键参数。直观理解：在圆柱坐标中，$\mathrm{d}\phi$ 本身不是长度，乘以 $\rho$（即 $h_\phi$）后才变成弧长 $\rho\,\mathrm{d}\phi$。

## 1.3 标量场的方向导数与梯度

### 什么是"场"？—— 建立一个直观图像

> **场的定义**：如果空间中每一点在每一时刻都有一个确定的物理量值，就说在这个空间中建立了该物理量的**场**。

**类比理解**：想象一个房间，你在每个位置放一个温度计，读到的温度都不一样，这些温度值一起构成了"温度场"。类似地：
- 温度场 $\rightarrow$ 标量场（只有数值，没有方向）
- 电场 $\mathbf{E}$ $\rightarrow$ 矢量场（有数值，也有方向）
- 流速场 $\mathbf{v}$ $\rightarrow$ 矢量场

**两种分类**：

| 分类方式 | 类型 | 例子 |
|----------|------|------|
| 按物理量性质 | 标量场（用 $u$ 表示） | 温度、电位、密度 |
| 按物理量性质 | 矢量场（用 $\mathbf{F}$ 表示） | 电场、磁场、力场 |
| 按时间依赖 | 静态场 $u(\mathbf{r})$ | 恒定温度分布 |
| 按时间依赖 | 时变场 $u(\mathbf{r}, t)$ | 交变电磁场 |

本书先讨论静态场，因为时变场在每一瞬时时刻的数学处理方式是一样的。

---

### 1.3.1 标量场的等值面

#### 概念

对于标量场 $u(\mathbf{r})$，把所有场值相同的点连起来，形成的曲面叫**等值面**：

$$u(\mathbf{r}) = C$$

其中 $C$ 是常数。

#### 直观类比

就像地形图上的**等高线**：
- 同一条等高线上所有点的海拔相同
- 不同等高线代表不同的海拔
- 等高线永远不会交叉（因为一个点只能有一个海拔）

在三维空间中，等温面、等位面就是等高线概念的三维推广。

#### 等值面的三个性质

1. **形成一族曲面**：取不同的 $C$ 值，得到不同的等值面，它们充满整个空间
2. **过每一点有且仅有一个等值面**
3. **等值面互不相交**（因为标量函数是单值的——一个点不能同时有两个不同的场值）

> **为什么要学等值面？** 因为它和后面的梯度方向有直接关系：梯度方向就是等值面的法线方向！

---

### 1.3.2 方向导数 —— "沿着某个方向，场变化有多快？"

#### 动机

等值面告诉我们场的"地形"，但它没有回答一个问题：

> 站在场中某一点，**朝某个方向走**，场值的变化率是多少？

这就是**方向导数**要解决的问题。

#### 定义

设 $M_0$ 是标量场 $u$ 中的一点，从 $M_0$ 出发沿方向 $\mathbf{l}$ 走一段距离 $\Delta l$ 到达点 $M$，场值从 $u(M_0)$ 变为 $u(M)$。

**方向导数**定义为：

$$\boxed{\left.\frac{\partial u}{\partial l}\right|_{M_0} = \lim_{\Delta l \to 0} \frac{u(M) - u(M_0)}{\Delta l}} \tag{1.3.5}$$

**物理含义**：函数 $u$ 在点 $M_0$ 处沿方向 $\mathbf{l}$ 的**空间变化率**。

- $\dfrac{\partial u}{\partial l} > 0$：沿着 $\mathbf{l}$ 方向走，场值**增大**
- $\dfrac{\partial u}{\partial l} < 0$：沿着 $\mathbf{l}$ 方向走，场值**减小**
- $\dfrac{\partial u}{\partial l} = 0$：沿着 $\mathbf{l}$ 方向走，场值不变（沿等值面切线方向）

#### 直角坐标系中的计算公式（推导）

这是本节**第一个重要推导**，思路很简单：用链式法则。

设射线 $\mathbf{l}$ 与三个坐标轴的夹角分别为 $\alpha, \beta, \gamma$，则它的**方向余弦**为 $(\cos\alpha, \cos\beta, \cos\gamma)$。

根据多元函数链式法则：

$$\frac{\partial u}{\partial l} = \frac{\partial u}{\partial x}\frac{\mathrm{d}x}{\mathrm{d}l} + \frac{\partial u}{\partial y}\frac{\mathrm{d}y}{\mathrm{d}l} + \frac{\partial u}{\partial z}\frac{\mathrm{d}z}{\mathrm{d}l}$$

现在关键一步：$\dfrac{\mathrm{d}x}{\mathrm{d}l}$ 是什么？

沿 $\mathbf{l}$ 方向移动 $\mathrm{d}l$，在 $x$ 轴上的投影增量就是 $\mathrm{d}l \cdot \cos\alpha$，所以：

$$\frac{\mathrm{d}x}{\mathrm{d}l} = \cos\alpha,\quad \frac{\mathrm{d}y}{\mathrm{d}l} = \cos\beta,\quad \frac{\mathrm{d}z}{\mathrm{d}l} = \cos\gamma$$

代入得到直角坐标系中方向导数的计算公式：

$$\boxed{\frac{\partial u}{\partial l} = \frac{\partial u}{\partial x}\cos\alpha + \frac{\partial u}{\partial y}\cos\beta + \frac{\partial u}{\partial z}\cos\gamma} \tag{1.3.6}$$

> **直观理解**：方向导数 = 三个偏导数分别用方向余弦加权求和。方向余弦告诉你"这个方向在 $x, y, z$ 三个轴上各占多少分量"。

### 1.3.3 梯度 —— "变化最快的方向是哪个？变化率最大是多少？"

#### 动机

从同一点出发，有**无穷多个**方向可以走。方向导数随方向不同而不同。一个自然的问题是：

> 沿着**哪个方向**走，场值变化最快？这个最大的变化率是多少？

这就是**梯度**要回答的问题。

#### 梯度的定义

标量场 $u$ 在点 $M$ 处的**梯度**记作 $\mathbf{grad}\,u$（或 $\nabla u$），它是一个**矢量**，定义为：

$$\boxed{\mathbf{e}_l \cdot \mathbf{grad}\,u = \frac{\partial u}{\partial l}} \tag{1.3.7}$$

这句话的意思是：梯度在任意方向 $\mathbf{e}_l$ 上的**投影**，等于沿该方向的方向导数。

#### 从 (1.3.7) 到 (1.3.8) —— 为什么梯度指向变化最快的方向？

这是理解梯度的**最关键一段**。我们先回顾两个公式各自的角色：

| 公式 | 角色 | 含义 |
|------|------|------|
| (1.3.7) $\mathbf{e}_l \cdot \mathbf{grad}\,u = \dfrac{\partial u}{\partial l}$ | **隐式定义** | 告诉你梯度**能做什么**：在任意方向上的投影 = 该方向的方向导数 |
| (1.3.8) $\mathbf{grad}\,u = \mathbf{e}_n\!\left.\dfrac{\partial u}{\partial l}\right|_{\max}$ | **显式表达** | 告诉你梯度**是什么**：方向 = 变化最快的方向，大小 = 最大变化率 |

下面分四步，把 (1.3.8) 从 (1.3.7) 中推导出来。

**第一步：写出投影公式。**

从 (1.3.7) 出发：

$$\frac{\partial u}{\partial l} = \mathbf{e}_l \cdot \mathbf{grad}\,u = |\mathbf{grad}\,u| \cdot |\mathbf{e}_l| \cdot \cos\theta$$

因为 $\mathbf{e}_l$ 是单位矢量（$|\mathbf{e}_l| = 1$），$\theta$ 是 $\mathbf{e}_l$ 与 $\mathbf{grad}\,u$ 的夹角，所以：

$$\frac{\partial u}{\partial l} = |\mathbf{grad}\,u| \cdot \cos\theta \tag{A}$$

**第二步：分析 $\cos\theta$ 的范围。**

在**同一点**上，$|\mathbf{grad}\,u|$ 是固定的（它只取决于这个点），方向导数 $\partial u/\partial l$ 随方向 $\mathbf{e}_l$ 的变化**完全由 $\cos\theta$ 控制**：

| $\theta$ | $\cos\theta$ | $\partial u/\partial l$ | 含义 |
|-----------|--------------|------------------------|------|
| $0$ | $1$ | $|\mathbf{grad}\,u|$ | **最大**（沿梯度方向） |
| $(0, \pi/2)$ | $(0, 1)$ | 介于 0 和最大值之间 | 部分沿梯度方向 |
| $\pi/2$ | $0$ | $0$ | 垂直于梯度，变化率为零 |
| $(\pi/2, \pi)$ | $(-1, 0)$ | 负值 | 部分逆梯度方向 |
| $\pi$ | $-1$ | $-|\mathbf{grad}\,u|$ | **最小**（逆梯度方向） |

**第三步：锁定最大值对应的方向。**

当 $\partial u/\partial l$ 取到**最大值**时，必须有 $\cos\theta = 1$，即 $\theta = 0$。

$\theta = 0$ 意味着 $\mathbf{e}_l \parallel \mathbf{grad}\,u$（方向相同）。记这个特殊的方向为 $\mathbf{e}_n$，则：

$$\mathbf{e}_n = \frac{\mathbf{grad}\,u}{|\mathbf{grad}\,u|}$$

同时，此时的方向导数值就是梯度的模长：

$$\left.\frac{\partial u}{\partial l}\right|_{\max} = |\mathbf{grad}\,u|$$

**第四步：拼出显式表达式。**

把方向 $\mathbf{e}_n$ 和大小 $|\mathbf{grad}\,u|$ 合起来：

$$\mathbf{grad}\,u = |\mathbf{grad}\,u| \cdot \mathbf{e}_n = \mathbf{e}_n \left.\frac{\partial u}{\partial l}\right|_{\max}$$

这就得到了 **(1.3.8)**：

$$\boxed{\mathbf{grad}\,u = \mathbf{e}_n \left.\frac{\partial u}{\partial l}\right|_{\max}} \tag{1.3.8}$$

**反向验证：把 (1.3.8) 代回 (1.3.7)，等式还成立吗？**

把 $\mathbf{grad}\,u = \mathbf{e}_n \left.\frac{\partial u}{\partial l}\right|_{\max}$ 代入 (1.3.7) 的左边：

$$\begin{aligned}
\mathbf{e}_l \cdot \mathbf{grad}\,u
&= \mathbf{e}_l \cdot \left( \mathbf{e}_n \left.\frac{\partial u}{\partial l}\right|_{\max} \right) \\[4pt]
&= (\mathbf{e}_l \cdot \mathbf{e}_n) \cdot \left.\frac{\partial u}{\partial l}\right|_{\max} \\[4pt]
&= \cos\theta \cdot \left.\frac{\partial u}{\partial l}\right|_{\max}
\end{aligned}$$

根据 (A) 式，$\cos\theta \cdot |\mathbf{grad}\,u| = \cos\theta \cdot \left.\frac{\partial u}{\partial l}\right|_{\max}$ 就是 $\partial u/\partial l$。完全成立，两式等价。

**形象理解："万能遥控器"类比。**

把梯度想象成一个**万能遥控器**：

- **(1.3.7)** 告诉你遥控器的**操作方法**：按下"方向 $\mathbf{e}_l$"按钮，就输出该方向的方向导数。操作方式是"点乘"。
- **(1.3.8)** 告诉你遥控器的**内部构造**：它本身有一个固定的指向（变化最快的方向 $\mathbf{e}_n$）和一个固定的强度（最大变化率）。

两个公式从不同角度描述同一个东西——(1.3.7) 是**行为定义**（能做什么），(1.3.8) 是**结构描述**（是什么）。推导路线如下：

```
(1.3.7):  e_l · grad u = ∂u/∂l       ← 隐式定义
                |
                | 令 θ 为 e_l 与 grad u 的夹角
                ↓
         ∂u/∂l = |grad u| cos θ
                |
                | 当 cos θ = 1（即 θ = 0）时取最大值
                ↓
(1.3.8):  grad u = e_n · (∂u/∂l)|_max  ← 显式表达
```

**物理图像**：
- 梯度的**方向** = 标量场变化最快的方向 = 等值面的**法线方向**
- 梯度的**大小** = 最大的方向导数值
- 梯度总是指向 $u$ **增加**的方向（因为 $|\mathbf{grad}\,u| \ge 0$）

#### 梯度垂直于等值面的几何证明

这是一个很漂亮的几何论证：

设 $u = u_0$ 和 $u = u_0 + \mathrm{d}u$（$\mathrm{d}u > 0$）是两个靠得很近的等值面。

从 $u_0$ 面上的点出发，要到达 $u_0 + \mathrm{d}u$ 面：
- 函数值的改变量 $\mathrm{d}u$ 是固定的
- 但走的路程 $\mathrm{d}l$ 取决于方向

沿**法线方向**走：路程 $\mathrm{d}l_n$ 最短 → 变化率 $\mathrm{d}u/\mathrm{d}l_n$ 最大 → 这就是梯度方向！

沿等值面的**切线方向**走：永远在同一个等值面上 → $\mathrm{d}u = 0$ → 方向导数为零。

> **结论**：梯度 $\perp$ 等值面，指向 $u$ 增加的一侧。

#### 直角坐标系中梯度的表达式（推导）

利用方向导数的公式 (1.3.6) 和梯度的定义 (1.3.7)：

$$\frac{\partial u}{\partial l} = \frac{\partial u}{\partial x}\cos\alpha + \frac{\partial u}{\partial y}\cos\beta + \frac{\partial u}{\partial z}\cos\gamma$$

同时，方向余弦可以写成：$\cos\alpha = \mathbf{e}_l \cdot \mathbf{e}_x$，等等。所以：

$$\frac{\partial u}{\partial l} = \mathbf{e}_l \cdot \left(\mathbf{e}_x\frac{\partial u}{\partial x} + \mathbf{e}_y\frac{\partial u}{\partial y} + \mathbf{e}_z\frac{\partial u}{\partial z}\right)$$

对比梯度定义 $\dfrac{\partial u}{\partial l} = \mathbf{e}_l \cdot \mathbf{grad}\,u$，得到：

$$\boxed{\mathbf{grad}\,u = \mathbf{e}_x\frac{\partial u}{\partial x} + \mathbf{e}_y\frac{\partial u}{\partial y} + \mathbf{e}_z\frac{\partial u}{\partial z}} \tag{1.3.9}$$

#### 哈密顿算符 $\nabla$（nabla）

为了方便，引入一个符号：

$$\boxed{\nabla = \mathbf{e}_x\frac{\partial}{\partial x} + \mathbf{e}_y\frac{\partial}{\partial y} + \mathbf{e}_z\frac{\partial}{\partial z}} \tag{1.3.10}$$

$\nabla$ 读作 "del" 或 "nabla"。它既是矢量，又是微分算符，具有**双重性质**。

于是梯度的简洁写法：

$$\boxed{\mathbf{grad}\,u = \nabla u}$$

> **理解**：$\nabla u$ 就是 "把 $\nabla$ 这个算符作用在标量函数 $u$ 上"。这里的"作用"就是分别对 $x,y,z$ 求偏导。

#### 三种坐标系中的梯度公式

这是1.2和1.3结合的**核心结果**：

| 坐标系 | 梯度 $\nabla u$ 的表达式 |
|--------|--------------------------|
| 直角坐标 | $\nabla u = \mathbf{e}_x\dfrac{\partial u}{\partial x} + \mathbf{e}_y\dfrac{\partial u}{\partial y} + \mathbf{e}_z\dfrac{\partial u}{\partial z}$ |
| 圆柱坐标 | $\nabla u = \mathbf{e}_\rho\dfrac{\partial u}{\partial \rho} + \mathbf{e}_\phi\dfrac{1}{\rho}\dfrac{\partial u}{\partial \phi} + \mathbf{e}_z\dfrac{\partial u}{\partial z}$ |
| 球坐标 | $\nabla u = \mathbf{e}_r\dfrac{\partial u}{\partial r} + \mathbf{e}_\theta\dfrac{1}{r}\dfrac{\partial u}{\partial \theta} + \mathbf{e}_\phi\dfrac{1}{r\sin\theta}\dfrac{\partial u}{\partial \phi}$ |

**观察规律**（非常有用的记忆技巧）：

$$ \nabla u = \sum_i \mathbf{e}_i \cdot \frac{1}{h_i}\frac{\partial u}{\partial q_i} $$

其中 $h_i$ 是度量系数。验证：
- 直角坐标：$h_x = h_y = h_z = 1$ ✓
- 圆柱坐标：$h_\rho=1,\ h_\phi=\rho,\ h_z=1$ → $\frac{1}{\rho}\frac{\partial u}{\partial\phi}$ ✓
- 球坐标：$h_r=1,\ h_\theta=r,\ h_\phi=r\sin\theta$ → $\frac{1}{r}\frac{\partial u}{\partial\theta},\ \frac{1}{r\sin\theta}\frac{\partial u}{\partial\phi}$ ✓

这就是为什么 1.2 讲度量系数——它是所有微分运算的统一钥匙！

> **答疑：度量系数 $h_\phi = \rho$、$h_\theta = r$、$h_\phi^{\text{(球)}} = r\sin\theta$ 是怎么来的？**
>
> 度量系数（拉梅系数）的定义是 $h_i = \mathrm{d}l_i/\mathrm{d}q_i$，即"实际长度元 ÷ 坐标微分"。但更根本的定义来自位置矢量：
>
> $$\boxed{h_i = \left|\frac{\partial\mathbf{r}}{\partial q_i}\right|} \tag{★}$$
>
> 即位置矢量对坐标 $q_i$ 求偏导之后的**模长**。下面逐一计算。
>
> **直角坐标系**（用作参照）：
>
> $\mathbf{r} = x\mathbf{e}_x + y\mathbf{e}_y + z\mathbf{e}_z$
>
> $$\frac{\partial\mathbf{r}}{\partial x} = \mathbf{e}_x \;\Rightarrow\; h_x = 1,\quad \frac{\partial\mathbf{r}}{\partial y} = \mathbf{e}_y \;\Rightarrow\; h_y = 1,\quad \frac{\partial\mathbf{r}}{\partial z} = \mathbf{e}_z \;\Rightarrow\; h_z = 1$$
>
> **圆柱坐标系**（用直角坐标基底表示 $\mathbf{r}$）：
>
> $\mathbf{r} = \rho\cos\phi\,\mathbf{e}_x + \rho\sin\phi\,\mathbf{e}_y + z\,\mathbf{e}_z$
>
> $$\begin{aligned}
> \frac{\partial\mathbf{r}}{\partial\rho} &= \cos\phi\,\mathbf{e}_x + \sin\phi\,\mathbf{e}_y, &\left|\frac{\partial\mathbf{r}}{\partial\rho}\right| &= \sqrt{\cos^2\phi + \sin^2\phi} = 1 \;\Rightarrow\; h_\rho = 1 \\[4pt]
> \frac{\partial\mathbf{r}}{\partial\phi} &= -\rho\sin\phi\,\mathbf{e}_x + \rho\cos\phi\,\mathbf{e}_y, &\left|\frac{\partial\mathbf{r}}{\partial\phi}\right| &= \rho\sqrt{\sin^2\phi + \cos^2\phi} = \rho \;\Rightarrow\; h_\phi = \rho \\[4pt]
> \frac{\partial\mathbf{r}}{\partial z} &= \mathbf{e}_z, &\left|\frac{\partial\mathbf{r}}{\partial z}\right| &= 1 \;\Rightarrow\; h_z = 1
> \end{aligned}$$
>
> $h_\phi = \rho$ 的几何直觉：离 $z$ 轴越远，转同样的角度走过的弧长越长——这正是弧长公式 $\mathrm{d}l = \rho\,\mathrm{d}\phi$。
>
> **球坐标系**：
>
> $\mathbf{r} = r\sin\theta\cos\phi\,\mathbf{e}_x + r\sin\theta\sin\phi\,\mathbf{e}_y + r\cos\theta\,\mathbf{e}_z$
>
> $$\begin{aligned}
> \frac{\partial\mathbf{r}}{\partial r} &= \sin\theta\cos\phi\,\mathbf{e}_x + \sin\theta\sin\phi\,\mathbf{e}_y + \cos\theta\,\mathbf{e}_z, &\left|\frac{\partial\mathbf{r}}{\partial r}\right| &= 1 \;\Rightarrow\; h_r = 1 \\[4pt]
> \frac{\partial\mathbf{r}}{\partial\theta} &= r\cos\theta\cos\phi\,\mathbf{e}_x + r\cos\theta\sin\phi\,\mathbf{e}_y - r\sin\theta\,\mathbf{e}_z, &\left|\frac{\partial\mathbf{r}}{\partial\theta}\right| &= r \;\Rightarrow\; h_\theta = r \\[4pt]
> \frac{\partial\mathbf{r}}{\partial\phi} &= -r\sin\theta\sin\phi\,\mathbf{e}_x + r\sin\theta\cos\phi\,\mathbf{e}_y, &\left|\frac{\partial\mathbf{r}}{\partial\phi}\right| &= r\sin\theta \;\Rightarrow\; h_\phi^{\text{(球)}} = r\sin\theta
> \end{aligned}$$
>
> $h_\theta = r$ 的几何直觉：$\theta$ 是极角（从 $z$ 轴量起），沿经线方向的弧长 = $r\,\mathrm{d}\theta$。
>
> $h_\phi^{\text{(球)}} = r\sin\theta$ 的几何直觉：$\phi$ 方向的弧长取决于纬度圈的半径 $r\sin\theta$（赤道最大，极点退化到零）。
>
> **统一规律**：
>
> | 坐标系 | $h = 1$ 的坐标 | $h \neq 1$ 的坐标 |
> |--------|---------------|-------------------|
> | 直角 | $x, y, z$（全为长度坐标） | 无 |
> | 圆柱 | $\rho, z$（长度坐标） | $\phi$（角度，$h = \rho$） |
> | 球 | $r$（长度坐标） | $\theta$（角度，$h = r$），$\phi$（角度，$h = r\sin\theta$） |
>
> **为什么梯度公式中度量系数在分母上？**
>
> 梯度的物理含义是**对实际距离的变化率**。偏导 $\partial u/\partial q_i$ 是"对坐标的变化率"，除以 $h_i$ 后才变成"对真实距离的变化率"：
>
> $$\frac{\partial u}{\partial l_i} = \frac{1}{h_i}\frac{\partial u}{\partial q_i}$$
>
> 例如在圆柱坐标中，$\partial u/\partial\phi$ 的单位是"每弧度"，除以 $h_\phi = \rho$ 后变成"每米"。三个正交方向合起来就是：
>
> $$\nabla u = \mathbf{e}_1\frac{\partial u}{\partial l_1} + \mathbf{e}_2\frac{\partial u}{\partial l_2} + \mathbf{e}_3\frac{\partial u}{\partial l_3} = \sum_i \mathbf{e}_i \cdot \frac{1}{h_i}\frac{\partial u}{\partial q_i}$$

#### 梯度的三个核心性质（总结）

| 性质 | 内容 |
|------|------|
| ① | $\nabla u$ 是一个**矢量场**（标量场 $u$ 产生梯度场 $\nabla u$） |
| ② | 任意方向的方向导数 = 梯度在该方向上的投影：$\dfrac{\partial u}{\partial l} = \nabla u \cdot \mathbf{e}_l$ |
| ③ | 梯度 $\perp$ 等值面，指向 $u$ **增加**的方向 |

---

### 1.3.4 梯度的运算规则

梯度满足以下运算规则（可以类比求导运算来记）：

| 规则 | 公式 | 记忆方法 |
|------|------|----------|
| 常数倍 | $\nabla(Cu) = C\nabla u$ | 常数可以提出来 |
| 和差 | $\nabla(u \pm v) = \nabla u \pm \nabla v$ | 线性运算 |
| 乘积 | $\nabla(uv) = v\nabla u + u\nabla v$ | 类似 $(uv)' = u'v + uv'$ |
| 商 | $\nabla\!\left(\dfrac{u}{v}\right) = \dfrac{v\nabla u - u\nabla v}{v^2}$ | 类似 $(u/v)' = (u'v - uv')/v^2$ |
| 复合函数 | $\nabla f(u) = f'(u)\,\nabla u$ | 链式法则 |

### 1.3.5 例题 1.3.1 —— 电磁场中最常用的三个梯度公式

> **例题**：已知 $\mathbf{R} = \mathbf{e}_x(x-x') + \mathbf{e}_y(y-y') + \mathbf{e}_z(z-z')$，$R = |\mathbf{R}|$。
> 证明：
> 1. $\nabla R = \dfrac{\mathbf{R}}{R}$
> 2. $\nabla\!\left(\dfrac{1}{R}\right) = -\dfrac{\mathbf{R}}{R^3}$
> 3. $\nabla f(R) = -\nabla' f(R)$

**背景说明**：在电磁场中，$(x', y', z')$ 代表**源点**（电荷/电流所在位置），$(x, y, z)$ 代表**场点**（我们观察场的位置）。$\mathbf{R}$ 是从源点指向场点的矢量，$R$ 是两点之间的距离。这三个公式在后续计算电场、电位时会反复出现！

#### (1) 证明 $\nabla R = \mathbf{R}/R$

首先写出 $R$ 的表达式：

$$R = |\mathbf{R}| = \sqrt{(x-x')^2 + (y-y')^2 + (z-z')^2}$$

目标是求 $\nabla R = \mathbf{e}_x\dfrac{\partial R}{\partial x} + \mathbf{e}_y\dfrac{\partial R}{\partial y} + \mathbf{e}_z\dfrac{\partial R}{\partial z}$。先集中精力算 $\partial R/\partial x$（$\partial R/\partial y$ 和 $\partial R/\partial z$ 完全类似）。

**第一步：引入中间变量，看清函数嵌套结构。**

令根号里面的内容为 $S$：

$$S = (x-x')^2 + (y-y')^2 + (z-z')^2$$

则 $R = \sqrt{S}$。此时求导路线是：

```
R = √S                           ← R 是 S 的一元函数
 │
 └── S = (x-x')² + (y-y')² + (z-z')²   ← S 是 x, y, z 的三元函数
      │
      └── x                       ← 自变量
```

**第二步：应用链式法则。**

$$\frac{\partial R}{\partial x} = \frac{\mathrm{d}R}{\mathrm{d}S} \cdot \frac{\partial S}{\partial x}$$

> 为什么 $R$ 对 $S$ 用 $\mathrm{d}$？因为 $R = \sqrt{S}$ 是一元函数关系，本质上和 $y = \sqrt{t}$ 一样，应该用常微分符号 $\mathrm{d}$。
>
> 为什么 $S$ 对 $x$ 用 $\partial$？因为 $S$ 依赖于 $x, y, z$ 三个变量，对其中一个求导时其余视为常数，应该用偏导符号 $\partial$。

**第三步：分别计算两项。**

*外层求导* —— $R = S^{1/2}$，按幂函数求导公式 $(t^{1/2})' = \frac{1}{2}t^{-1/2}$：

$$\frac{\mathrm{d}R}{\mathrm{d}S} = \frac{1}{2}S^{-1/2} = \frac{1}{2\sqrt{S}} = \frac{1}{2R}$$

*内层求导* —— $S$ 对 $x$ 求偏导时，$y, y', z, z', x'$ 都是常数：

$$\frac{\partial S}{\partial x} = \frac{\partial}{\partial x}\Bigl[(x-x')^2 + (y-y')^2 + (z-z')^2\Bigr]$$

第二项 $(y-y')^2$ 不含 $x$，偏导为零；第三项 $(z-z')^2$ 同理。只剩第一项：

$$\frac{\partial S}{\partial x} = \frac{\partial}{\partial x}\bigl[(x-x')^2\bigr]$$

对 $(x-x')^2$ 求导，用幂函数求导公式（或再套一次链式法则）：

$$\frac{\partial}{\partial x}\bigl[(x-x')^2\bigr] = 2(x-x') \cdot \frac{\partial}{\partial x}(x-x') = 2(x-x') \cdot 1 = 2(x-x')$$

**第四步：合起来。**

$$\frac{\partial R}{\partial x} = \underbrace{\frac{1}{2R}}_{\mathrm{d}R/\mathrm{d}S} \cdot \underbrace{2(x-x')}_{\partial S/\partial x} = \frac{x-x'}{R}$$

**第五步：类比写出另外两个偏导。**

$y$ 和 $z$ 的求导过程完全对称，只需把 $x$ 换成 $y$ 或 $z$：

$$\frac{\partial R}{\partial y} = \frac{y-y'}{R},\qquad \frac{\partial R}{\partial z} = \frac{z-z'}{R}$$

**第六步：合成梯度。**

$$\nabla R = \mathbf{e}_x\frac{x-x'}{R} + \mathbf{e}_y\frac{y-y'}{R} + \mathbf{e}_z\frac{z-z'}{R} = \frac{\mathbf{R}}{R}$$

> **补充**：笔记中常用的速写法 $\frac{\partial R}{\partial x} = \frac{1}{2\sqrt{(\cdots)}} \cdot 2(x-x')$ 其实就是"心算链式法则"——对根号求导 = $\frac{1}{2\times\text{根号}}$ × 根号里面的东西再对 $x$ 求导。设 $S$ 拆开写是为了看清结构，熟练之后两步可以一步完成。

> **物理图像**：$\mathbf{R}/R$ 就是从源点指向场点的**单位方向矢量**。梯度的方向就是 $\mathbf{R}$ 的方向——距离增加最快的方向就是直接远离源点的方向，这非常直观！

#### (2) 证明 $\nabla(1/R) = -\mathbf{R}/R^3$

把 $1/R$ 看成复合函数 $f(R) = R^{-1}$，利用链式法则 $\nabla f(R) = f'(R)\nabla R$：

$$\nabla\!\left(\frac{1}{R}\right) = \frac{\mathrm{d}}{\mathrm{d}R}\!\left(\frac{1}{R}\right) \cdot \nabla R = -\frac{1}{R^2} \cdot \frac{\mathbf{R}}{R} = -\frac{\mathbf{R}}{R^3}$$

或者直接做偏导数（验证）：

$$\frac{\partial}{\partial x}\!\left(\frac{1}{R}\right) = -\frac{1}{R^2}\frac{\partial R}{\partial x} = -\frac{x-x'}{R^3}$$

三个分量合起来就是 $-\mathbf{R}/R^3$。

> **物理图像**：在电磁学中，点电荷的电场 $\mathbf{E} \propto \mathbf{R}/R^3$，电位 $\varphi \propto 1/R$，电场是电位的**负梯度**：$\mathbf{E} = -\nabla\varphi$。这就是为什么 $-\nabla(1/R) = \mathbf{R}/R^3$ 如此重要！

#### (3) 证明 $\nabla f(R) = -\nabla' f(R)$

**先算 $\nabla f(R)$**（对场点坐标求梯度，前面已经熟练了）。

由链式法则 $\nabla f(R) = f'(R)\nabla R$，而第 (1) 问已知 $\nabla R = \mathbf{R}/R$，所以：

$$\nabla f(R) = f'(R)\frac{\mathbf{R}}{R} \tag{3a}$$

**再算 $\nabla' f(R)$**（对源点坐标求梯度）。这是本问的核心。

$\nabla'$ 的定义是对源点坐标 $(x', y', z')$ 求偏导：

$$\nabla' f(R) = \mathbf{e}_x\frac{\partial f(R)}{\partial x'} + \mathbf{e}_y\frac{\partial f(R)}{\partial y'} + \mathbf{e}_z\frac{\partial f(R)}{\partial z'}$$

先用链式法则把 $f(R)$ 拆开（$f$ 是 $R$ 的一元函数，$R$ 是 $x',y',z'$ 的多元函数）：

$$\nabla' f(R) = f'(R)\,\nabla' R$$

所以问题归结为求 $\nabla' R$，即 $\partial R/\partial x'$、$\partial R/\partial y'$、$\partial R/\partial z'$。

**重点：$\partial R/\partial x'$ 和 $\partial R/\partial x$ 有什么不同？**

回到 $R$ 的表达式（和第 (1) 问完全一样）：

$$R = \sqrt{(x-x')^2 + (y-y')^2 + (z-z')^2}$$

令 $S = (x-x')^2 + (y-y')^2 + (z-z')^2$，则 $R = \sqrt{S}$。

同样用链式法则：

$$\frac{\partial R}{\partial x'} = \frac{\mathrm{d}R}{\mathrm{d}S} \cdot \frac{\partial S}{\partial x'}$$

外层求导和之前**完全相同**：

$$\frac{\mathrm{d}R}{\mathrm{d}S} = \frac{1}{2\sqrt{S}} = \frac{1}{2R}$$

内层求导 —— 这里是关键区别。现在是对 $x'$ 求偏导（$x$ 是常数）：

$$\frac{\partial S}{\partial x'} = \frac{\partial}{\partial x'}\Bigl[(x-x')^2 + (y-y')^2 + (z-z')^2\Bigr]$$

只有第一项含 $x'$（第二项含 $y'$、第三项含 $z'$，对 $x'$ 求导时都为零）：

$$\frac{\partial S}{\partial x'} = \frac{\partial}{\partial x'}\bigl[(x-x')^2\bigr]$$

对 $(x-x')^2$ 求导，链式法则：

$$\frac{\partial}{\partial x'}\bigl[(x-x')^2\bigr] = 2(x-x') \cdot \frac{\partial}{\partial x'}(x-x')$$

**这里就是负号的来源！**

$$\frac{\partial}{\partial x'}(x-x') = \frac{\partial}{\partial x'}(x) - \frac{\partial}{\partial x'}(x') = 0 - 1 = -1$$

> 对比第 (1) 问：$\frac{\partial}{\partial x}(x-x') = 1 - 0 = +1$。一模一样的位置，只是 $x$ 和 $x'$ 的角色互换了。

所以：

$$\frac{\partial S}{\partial x'} = 2(x-x') \cdot (-1) = -2(x-x')$$

合起来：

$$\frac{\partial R}{\partial x'} = \underbrace{\frac{1}{2R}}_{\mathrm{d}R/\mathrm{d}S} \cdot \underbrace{\bigl[-2(x-x')\bigr]}_{\partial S/\partial x'} = -\frac{x-x'}{R}$$

**对照表**（同一套链式法则，只差一个负号）：

| 步骤 | 对 $x$ 求导（第 (1) 问） | 对 $x'$ 求导（本问） |
|------|--------------------------|----------------------|
| 外层 $\mathrm{d}R/\mathrm{d}S$ | $\dfrac{1}{2R}$ | $\dfrac{1}{2R}$（相同） |
| 内层 $\partial S/\partial(\cdot)$ | $2(x-x') \cdot (+1)$ | $2(x-x') \cdot (-1)$ |
| 结果 | $\dfrac{x-x'}{R}$ | $-\dfrac{x-x'}{R}$ |

同理，对 $y'$ 和 $z'$ 完全对称：

$$\frac{\partial R}{\partial y'} = -\frac{y-y'}{R},\qquad \frac{\partial R}{\partial z'} = -\frac{z-z'}{R}$$

三个分量合起来：

$$\nabla' R = \mathbf{e}_x\left(-\frac{x-x'}{R}\right) + \mathbf{e}_y\left(-\frac{y-y'}{R}\right) + \mathbf{e}_z\left(-\frac{z-z'}{R}\right) = -\frac{\mathbf{R}}{R}$$

**收尾**：

$$\nabla' f(R) = f'(R)\,\nabla' R = f'(R)\left(-\frac{\mathbf{R}}{R}\right) = -f'(R)\frac{\mathbf{R}}{R}$$

和 (3a) 式对比，$\nabla f(R) = +f'(R)\frac{\mathbf{R}}{R}$，所以：

$$\boxed{\nabla f(R) = -\nabla' f(R)}$$

> **一句话总结**：整个推导的关键只有一行——$\frac{\partial}{\partial x'}(x-x') = -1$ 而 $\frac{\partial}{\partial x}(x-x') = +1$。除了这个负号，两次求导的步骤完全一样。

> **关于 $\nabla'$ 符号的常见困惑**：
>
> 初学者容易把 $\nabla'$ 上的"撇"理解为"求了一次导"，但实际上它的含义更简单——**换一套变量求导**：
>
> $$\nabla = \left(\frac{\partial}{\partial x}, \frac{\partial}{\partial y}, \frac{\partial}{\partial z}\right), \qquad \nabla' = \left(\frac{\partial}{\partial x'}, \frac{\partial}{\partial y'}, \frac{\partial}{\partial z'}\right)$$
>
> 所以 $\nabla f(R)$ 和 $\nabla' f(R)$ 的关系，完全取决于 $\mathbf{R}$ 中 $x$ 和 $x'$ 的系数。设 $\mathbf{R}$ 的分量为 $(ax + bx')$：
>
> - 若 $a$ 和 $b$ **同号**（如 $R = x + x'$）：求导都得正号 → $\nabla f(R) = +\nabla' f(R)$
> - 若 $a$ 和 $b$ **异号**（如 $R = x - x'$，即 $\mathbf{R} = \mathbf{r} - \mathbf{r}'$）：求导一正一负 → $\nabla f(R) = -\nabla' f(R)$
>
> 电磁场中 $\mathbf{R} = \mathbf{r} - \mathbf{r}'$（场点减源点），$a = +1, b = -1$，所以必然差一个负号。这不是巧合，是 $\mathbf{R}$ 的几何定义决定的。

> **物理意义**：对场点求梯度 与 对源点求梯度，结果只差一个负号。这反映了"场点到源点的矢量"和"源点到场点的矢量"方向正好相反。在电磁场的很多定理推导中，这可以让我们自由地在"对场变量求导"和"对源变量求导"之间切换。
