## 1.1 信号的基本概念与分类

### 1.1.1 三种信号的区分

数字信号处理的学习起点，是搞清楚三种"信号"之间的区别：

| 信号类型 | 时间变量 | 幅度 | 例子 |
|----------|----------|------|------|
| **模拟信号** | 连续 $t$ | 连续 | 麦克风输出的电压波形 $x_a(t)$ |
| **时域离散信号** | 离散 $n$ | 连续 | $x(n) = 0.5^n u(n)$，$n$ 只能取整数，但 $x(n)$ 可以是任意实数 |
| **数字信号** | 离散 $n$ | 离散（量化） | 8-bit 量化后的采样值，幅度只能取 256 个值 |

**关键认识**：时域离散信号是模拟信号到数字信号的**中间形态**——时间上已经离散了，但幅度还没量化。本书主要讨论时域离散信号。

---

### 1.1.2 常用的时域离散序列

#### (1) 单位脉冲序列 $\delta(n)$

$$\boxed{\delta(n) = \begin{cases} 1 & n = 0 \\ 0 & n \neq 0 \end{cases}}$$

这是离散信号处理中最基础、最重要的序列。它扮演的角色类似于连续时间系统中的单位冲激函数 $\delta(t)$，但**没有** $\delta(t)$ 的数学困难（$\delta(n)$ 在 $n=0$ 处有确定值 1，不是"无穷大"）。

**任何序列都可以用 $\delta(n)$ 的移位加权和表示**：

$$x(n) = \sum_{k=-\infty}^{\infty} x(k)\delta(n-k)$$

> **直观理解**：把序列 $x(n)$ 想象成一串数值，每个值 $x(k)$ 位于位置 $k$ 处。上式的含义就是"在位置 $k$ 处放一个高为 $x(k)$ 的单位脉冲，然后把所有位置加起来"。

#### (2) 单位阶跃序列 $u(n)$

$$\boxed{u(n) = \begin{cases} 1 & n \geqslant 0 \\ 0 & n < 0 \end{cases}}$$

$\delta(n)$ 与 $u(n)$ 的关系：
- $\delta(n) = u(n) - u(n-1)$ —— 阶跃的"一跳"就是脉冲
- $u(n) = \sum_{k=0}^{\infty} \delta(n-k) = \sum_{k=-\infty}^{n} \delta(k)$ —— 脉冲的累加就是阶跃

#### (3) 矩形序列 $R_N(n)$

$$\boxed{R_N(n) = \begin{cases} 1 & 0 \leqslant n \leqslant N-1 \\ 0 & \text{其它} \end{cases}}$$

也可以写成：$R_N(n) = u(n) - u(n-N)$

#### (4) 实指数序列

$$x(n) = a^n u(n)$$

- $|a| < 1$：衰减（如 $0.5^n$，趋于 0）
- $|a| > 1$：增长（发散）
- $a = -1$：交替序列 $(-1)^n$

#### (5) 正弦序列

$$\boxed{x(n) = A\cos(\omega n + \varphi)}$$

其中：
- $A$ —— 幅度
- $\omega$ —— **数字频率**，单位是弧度（rad）（注意：$\omega$ 是无量纲的！）
- $\varphi$ —— 初始相位

#### (6) 复指数序列

$$x(n) = e^{(\sigma + j\omega)n} = e^{\sigma n} \cdot e^{j\omega n}$$

当 $\sigma = 0$ 时，$x(n) = e^{j\omega n} = \cos(\omega n) + j\sin(\omega n)$（欧拉公式）。

### 1.1.3 周期序列的判断 —— 重点公式与推导

#### 周期序列的定义

序列 $x(n)$ 是周期的，如果存在正整数 $N$，使得对所有 $n$：

$$x(n) = x(n + N)$$

最小的 $N$ 称为序列的**周期**。

#### 正弦序列的周期性判断 —— 核心推导

设 $x(n) = A\cos(\omega n + \varphi)$，假设它以 $N$ 为周期：

$$A\cos[\omega(n + N) + \varphi] = A\cos(\omega n + \omega N + \varphi) = A\cos(\omega n + \varphi)$$

要使上式对所有 $n$ 成立，必须有：

$$\omega N = 2\pi k \quad (k \text{ 为整数})$$

即：

$$\boxed{\frac{2\pi}{\omega} = \frac{N}{k}}$$

**判断准则**：

| $\frac{2\pi}{\omega}$ 的值 | 结论 |
|:-------------------------:|------|
| 有理数 | **周期序列**，周期 $N = \frac{2\pi}{\omega} \cdot k$（取使 $N$ 为整数的最小 $k$） |
| 无理数 | **非周期序列** |

> **推导细节**：为什么 $2\pi/\omega$ 必须是有理数？
>
> 从 $\omega N = 2\pi k$ 出发，$N/k = 2\pi/\omega$。$N$ 和 $k$ 都是整数，所以 $N/k$ 是有理数，因此 $2\pi/\omega$ 必须是有理数。周期 $N$ 等于分数 $2\pi/\omega$ 化为最简分数后的分子（如果 $k$ 取为使 $N$ 为整数的最小正整数）。

**例题**（来自教材习题3）：

(1) $x(n) = A\cos\left(\frac{3}{7}\pi n - \frac{\pi}{8}\right)$

$\omega = \frac{3}{7}\pi$，$\frac{2\pi}{\omega} = \frac{2\pi}{3\pi/7} = \frac{14}{3}$，有理数 → 周期序列。化为最简分数：分子 14，分母 3，取 $k=3$ 时 $N = 14$。周期 $T = 14$。

(2) $x(n) = e^{j(\frac{1}{8}n - \pi)}$

$\omega = \frac{1}{8}$，$\frac{2\pi}{\omega} = 16\pi$，无理数 → 非周期序列。

> **重要区别**：连续时间正弦信号 $\cos(\Omega t)$ **总是**周期的（周期 $T = 2\pi/\Omega$），但离散时间正弦序列**不一定**是周期的！这是因为 $n$ 只能取整数，要求经过整数个样本后波形恰好重复。

### 1.1.4 序列的基本运算

| 运算 | 定义 | 效果 |
|------|------|------|
| 移位 | $y(n) = x(n - n_0)$ | $n_0 > 0$：右移（延迟）；$n_0 < 0$：左移（超前） |
| 翻转 | $y(n) = x(-n)$ | 以 $n=0$ 为轴翻转 |
| 尺度变换 | $y(n) = x(an)$ | 抽取（$a>1$）或插值（$0<a<1$） |
| 相加 | $y(n) = x_1(n) + x_2(n)$ | 逐点相加 |
| 相乘 | $y(n) = x_1(n) \cdot x_2(n)$ | 逐点相乘 |

**序列的奇偶分解**（教材习题4的重要结论）：

任何实序列 $x(n)$ 都可以唯一地分解为偶对称序列和奇对称序列之和：

$$x(n) = x_e(n) + x_o(n)$$

其中：

$$\boxed{x_e(n) = \frac{1}{2}[x(n) + x(-n)]} \quad \text{（偶对称：} x_e(n) = x_e(-n) \text{）}$$

$$\boxed{x_o(n) = \frac{1}{2}[x(n) - x(-n)]} \quad \text{（奇对称：} x_o(n) = -x_o(-n) \text{）}$$

## 1.2 线性时不变（LTI）系统

### 1.2.1 系统的四个基本性质

#### (1) 线性

系统满足**叠加原理**：

$$\boxed{T[ax_1(n) + bx_2(n)] = aT[x_1(n)] + bT[x_2(n)]}$$

其中 $T[\cdot]$ 表示系统对输入的变换。上式包含两层含义：
- **齐次性**：$T[ax(n)] = aT[x(n)]$（输入放大 $a$ 倍，输出也放大 $a$ 倍）
- **可加性**：$T[x_1(n) + x_2(n)] = T[x_1(n)] + T[x_2(n)]$

**常见"陷阱"**：$y(n) = 2x(n) + 3$ 是**非线性**系统！因为 $T[ax(n)] = 2ax(n) + 3 \neq a(2x(n) + 3)$。常数项破坏了齐次性。

#### (2) 时不变性（移不变性）

输入延迟多少，输出也延迟多少：

$$\boxed{T[x(n - n_0)] = y(n - n_0)}$$

> **验证方法**：令输入为 $x(n-n_0)$，计算输出 $y'(n)$；再计算 $y(n-n_0)$；若 $y'(n) = y(n-n_0)$，则系统是时不变的。

**常见"陷阱"**：
- $y(n) = x(-n)$ 是**时变**的！因为 $T[x(n-n_0)] = x(-n-n_0) \neq x(-(n-n_0)) = y(n-n_0)$
- $y(n) = x(2n)$ 也是**时变**的！
- $y(n) = x(n)\sin(\omega n)$ 是**时变**的，因为正弦系数是 $n$ 的显函数。

#### (3) 因果性

输出只取决于**现在和过去**的输入，不取决于未来：

$$y(n) \text{ 只依赖于 } x(n), x(n-1), x(n-2), \ldots$$

> **物理意义**：因果系统是"物理可实现"的系统——不能提前预知未来的输入。

#### (4) 稳定性（BIBO稳定性）

**有界输入产生有界输出**（Bounded Input → Bounded Output）：

$$|x(n)| \leqslant M < \infty \ \Rightarrow\ |y(n)| \leqslant P < \infty$$

对于 LTI 系统，稳定性等价于单位脉冲响应**绝对可和**：

$$\boxed{\sum_{n=-\infty}^{\infty} |h(n)| < \infty}$$

---

### 1.2.2 LTI 系统的输入输出关系 —— 线性卷积

对于 LTI 系统，输出 $y(n)$ = 输入 $x(n)$ 与单位脉冲响应 $h(n)$ 的**线性卷积**：

$$\boxed{y(n) = x(n) * h(n) = \sum_{m=-\infty}^{\infty} x(m)h(n-m)} \tag{1}$$

**为什么是这个公式？** 推导思路：

1. 任何输入 $x(n)$ 可表示为 $\delta(n)$ 的移位加权和：$x(n) = \sum_m x(m)\delta(n-m)$
2. 由线性：$y(n) = T[\sum_m x(m)\delta(n-m)] = \sum_m x(m)T[\delta(n-m)]$
3. $T[\delta(n-m)]$ 就是系统对 $\delta(n-m)$ 的响应，记为 $h_m(n)$
4. 由时不变性：$h_m(n) = h(n-m)$
5. 所以 $y(n) = \sum_m x(m)h(n-m)$

> **直观理解**：LTI 系统的特性完全由 $h(n)$ 刻画。输出 = 输入在不同时刻的"碎片" × 系统对每个碎片的"响应模板"，然后叠加。

---

### 1.2.3 与单位脉冲序列的卷积

两个极其重要的恒等式：

$$\boxed{x(n) = x(n) * \delta(n)} \tag{2}$$

$$\boxed{x(n - n_0) = x(n) * \delta(n - n_0)} \tag{3}$$

**证明**（以 (3) 为例）：

$$x(n) * \delta(n - n_0) = \sum_{m=-\infty}^{\infty} x(m)\delta(n - n_0 - m)$$

令 $k = n - n_0 - m$，只有当 $k = 0$ 即 $m = n - n_0$ 时 $\delta$ 非零，所以：

$$= x(n - n_0) \cdot 1 = x(n - n_0)$$

> **意义**：$\delta(n)$ 在卷积中扮演"恒等元"的角色——任何序列与 $\delta$ 卷积就是自己。$\delta(n - n_0)$ 的作用就是把序列移到 $n_0$ 的位置。这两个恒等式在简化卷积计算时极其有用。

## 1.3 线性卷积的计算方法

解线性卷积有三种方法：**图解法（列表法）**、**解析法**、**MATLAB 计算**。本章重点在前两种。

---

### 1.3.1 图解法（列表法）

适用于短序列的卷积。核心步骤：**反折 → 移位 → 相乘 → 求和**。

以 $x(n) = R_4(n) = \{1,1,1,1\}$ 和 $h(n) = R_4(n) = \{1,1,1,1\}$（均从 $n=0$ 开始）为例：

| $h(k)$ | 1 | 1 | 1 | 1 | | | | $y(n)$ |
|--------|---|---|---|---|---|---|---|--------|
| $h(-k)$ | 1 | 1 | 1 | 1 | | | | $y(0)=1$ |
| $h(1-k)$ | | 1 | 1 | 1 | 1 | | | $y(1)=2$ |
| $h(2-k)$ | | | 1 | 1 | 1 | 1 | | $y(2)=3$ |
| $h(3-k)$ | | | | 1 | 1 | 1 | 1 | $y(3)=4$ |
| $h(4-k)$ | | | | | 1 | 1 | 1 | $y(4)=3$ |
| $h(5-k)$ | | | | | | 1 | 1 | $y(5)=2$ |
| $h(6-k)$ | | | | | | | 1 | $y(6)=1$ |

结果（带下划线表示 $n=0$ 的位置）：

$$y(n) = \{\underline{1}, 2, 3, 4, 3, 2, 1\}$$

---

### 1.3.2 解析法 —— 确定求和限的完整推导

解析法的**核心难点**是确定求和限。下面给出系统化的方法。

#### 卷积公式

$$y(n) = \sum_{m=-\infty}^{\infty} x(m)h(n-m)$$

#### 确定非零区间

设 $x(m)$ 的非零区间为 $m \in [a, b]$，$h(n-m)$ 的非零区间由 $h(k)$ 的非零区间 $k \in [c, d]$ 推出：$c \leqslant n-m \leqslant d$，即 $n - d \leqslant m \leqslant n - c$。

两个区间要**同时成立**（$m$ 取值必须落在两个区间的交集内）：

$$\max\{a,\ n-d\} \leqslant m \leqslant \min\{b,\ n-c\}$$

> **这行公式是整个解析法的精髓！** 它统一处理了所有 $n$ 的分段情况：交集为空时 $y(n)=0$，交集非空时求和上下限就是 max 和 min。

#### 例题：$y(n) = R_4(n) * R_4(n)$ 的完整计算

$R_4(m)$ 的非零区间：$0 \leqslant m \leqslant 3$

$R_4(n-m)$ 的非零区间：$0 \leqslant n-m \leqslant 3$，即 $n-3 \leqslant m \leqslant n$

交集条件：$\max\{0, n-3\} \leqslant m \leqslant \min\{3, n\}$

然后分段讨论 $n$：

| $n$ 的范围 | $\max\{0, n-3\}$ | $\min\{3, n\}$ | 求和 | $y(n)$ |
|:---------:|:---------------:|:------------:|------|:-----:|
| $n < 0$ | 交集为空 | | $0$ |
| $0 \leqslant n \leqslant 3$ | $0$ | $n$ | $\sum_{m=0}^{n} 1$ | $n+1$ |
| $4 \leqslant n \leqslant 6$ | $n-3$ | $3$ | $\sum_{m=n-3}^{3} 1$ | $7-n$ |
| $n > 6$ | 交集为空 | | $0$ |

写成统一的闭式表达式：

$$\boxed{y(n) = \begin{cases} n+1 & 0 \leqslant n \leqslant 3 \\ 7-n & 4 \leqslant n \leqslant 6 \\ 0 & \text{其它} \end{cases}}$$

#### 非零值区间的示意图辅助判断

当卷积的解析推导遇到困难时，画"非零值区间图"是极其有效的辅助手段：

```
(a) x(m):      [0, 1, 2, 3] 有值
(b) h(-m):     [-3, -2, -1, 0] 有值
(c) h(n-m)     n<0 时图形在左侧，与 (a) 无重叠
    0≤n≤3 时  重叠范围 [0, n]
    4≤n≤6 时  重叠范围 [n-3, 3]
    n>6 时    图形在右侧，与 (a) 无重叠
```

> 图像描述：想象两条线段在数轴上移动。$x(m)$ 固定在 $[0,3]$，$h(n-m)$ 随 $n$ 增大从左向右滑动。当 $h(n-m)$ 的支撑区间 $[n-3, n]$ 与 $[0, 3]$ 有交集时 $y(n)$ 非零。交集长度就是 $y(n)$ 的值（对本例而言）。

### 1.3.3 卷积的性质（教材习题9的推导补全）

#### (1) 交换律：$x(n) * h(n) = h(n) * x(n)$

证明：令 $m' = n - m$，则 $m = n - m'$，当 $m$ 从 $-\infty$ 到 $\infty$ 时，$m'$ 也从 $\infty$ 到 $-\infty$。

$$\begin{aligned}
x(n) * h(n) &= \sum_{m=-\infty}^{\infty} x(m)h(n-m) \\
&= \sum_{m'=\infty}^{-\infty} x(n-m')h(m') \quad (\text{令 } m' = n-m) \\
&= \sum_{m'=-\infty}^{\infty} h(m')x(n-m') \quad (\text{反转求和方向}) \\
&= h(n) * x(n)
\end{aligned}$$

> **补充步骤**：从第二行到第三行，不仅反转了方向，也交换了 $x$ 和 $h$ 乘积中因子的位置。$x(n-m')h(m') = h(m')x(n-m')$ 是显然的（乘积交换律）。

#### (2) 结合律：$x(n) * [h_1(n) * h_2(n)] = [x(n) * h_1(n)] * h_2(n)$

证明：
$$\begin{aligned}
x(n) * [h_1(n) * h_2(n)] &= \sum_{m=-\infty}^{\infty} x(m) \left[\sum_{k=-\infty}^{\infty} h_1(k) h_2(n-m-k)\right] \\
&= \sum_{k=-\infty}^{\infty} h_1(k) \left[\sum_{m=-\infty}^{\infty} x(m) h_2(n-k-m)\right] \quad (\text{交换求和次序}) \\
&= \sum_{k=-\infty}^{\infty} h_1(k) [x(n-k) * h_2(n-k)] \quad (\text{内层是 } x \text{ 与 } h_2 \text{ 的卷积再移位}) \\
&= h_1(n) * [x(n) * h_2(n)] = [x(n) * h_1(n)] * h_2(n)
\end{aligned}$$

> **补充说明**：关键一步是交换双重求和次序 $\sum_m \sum_k = \sum_k \sum_m$。这一步要求级数**绝对收敛**，对于有限长序列或绝对可和的无限长序列总是成立的。

#### (3) 分配律：$x(n) * [h_1(n) + h_2(n)] = x(n) * h_1(n) + x(n) * h_2(n)$

证明：
$$\begin{aligned}
x(n) * [h_1(n) + h_2(n)] &= \sum_{m=-\infty}^{\infty} x(m)[h_1(n-m) + h_2(n-m)] \\
&= \sum_{m=-\infty}^{\infty} x(m)h_1(n-m) + \sum_{m=-\infty}^{\infty} x(m)h_2(n-m) \\
&= x(n) * h_1(n) + x(n) * h_2(n)
\end{aligned}$$

## 1.4 线性常系数差分方程

### 1.4.1 差分方程的一般形式

$N$ 阶线性常系数差分方程：

$$\boxed{\sum_{k=0}^{N} a_k y(n-k) = \sum_{m=0}^{M} b_m x(n-m)}$$

通常取 $a_0 = 1$，写成：

$$y(n) = -\sum_{k=1}^{N} a_k y(n-k) + \sum_{m=0}^{M} b_m x(n-m)$$

> **物理含义**：当前输出 $y(n)$ 由两部分决定——(1) 过去 $N$ 个输出值的加权和（反馈/递归部分）；(2) 当前及过去 $M$ 个输入值的加权和（前馈部分）。

### 1.4.2 递推解法

给定初始条件（如 $y(-1), y(-2), \ldots$）和输入 $x(n)$，按 $n=0, 1, 2, \ldots$ 逐步计算 $y(n)$。

**例**（教材习题11）：求 $y(n) = \frac{1}{2}y(n-1) + x(n) + \frac{1}{2}x(n-1)$ 的单位脉冲响应。

令 $x(n) = \delta(n)$：

$$h(n) = \frac{1}{2}h(n-1) + \delta(n) + \frac{1}{2}\delta(n-1)$$

递推过程：

| $n$ | $h(n)$ 的计算 | 结果 |
|:---:|--------------|:----:|
| 0 | $h(0) = \frac{1}{2}h(-1) + \delta(0) + \frac{1}{2}\delta(-1) = 0 + 1 + 0$ | $1$ |
| 1 | $h(1) = \frac{1}{2}h(0) + \delta(1) + \frac{1}{2}\delta(0) = 0.5 + 0 + 0.5$ | $1$ |
| 2 | $h(2) = \frac{1}{2}h(1) + \delta(2) + \frac{1}{2}\delta(1) = 0.5 + 0 + 0$ | $\frac{1}{2}$ |
| 3 | $h(3) = \frac{1}{2}h(2) = \frac{1}{2} \cdot \frac{1}{2}$ | $\left(\frac{1}{2}\right)^2$ |
| $n \geqslant 1$ | $h(n) = \frac{1}{2}h(n-1)$ | $\left(\frac{1}{2}\right)^{n-1}$ |

归纳得到闭式：

$$\boxed{h(n) = \left(\frac{1}{2}\right)^{n-1} u(n-1) + \delta(n)}$$

> **递推法的优势**：不需要求解析解，按时间顺序一步步算就行，特别适合计算机实现（MATLAB 的 `filter` 函数）。但缺点是不容易看出系统的整体特性。

## 1.5 模拟信号的采样与恢复

### 1.5.1 采样定理 —— 本章最重要的频域公式

#### 理想采样

用周期冲激串 $p(t) = \sum_{n=-\infty}^{\infty} \delta(t - nT)$ 对模拟信号 $x_a(t)$ 进行理想采样：

$$\hat{x}_a(t) = x_a(t) \cdot p(t) = \sum_{n=-\infty}^{\infty} x_a(nT)\delta(t - nT)$$

#### 频域关系 —— 核心公式

$$\boxed{\hat{X}_a(j\Omega) = \frac{1}{T}\sum_{k=-\infty}^{\infty} X_a(j\Omega - jk\Omega_s)} \tag{4}$$

其中 $\Omega_s = \frac{2\pi}{T}$ 是采样角频率。

> **公式解读**：采样后信号的频谱 = 原信号频谱的**周期延拓**（每隔 $\Omega_s$ 重复一次），幅度乘以 $1/T$。

#### 从频域延拓到采样定理的推导

原模拟信号 $x_a(t)$ 的频谱 $X_a(j\Omega)$ 假设是**带限**的，最高频率为 $\Omega_h$。

采样后频谱 $\hat{X}_a(j\Omega)$ 是 $X_a(j\Omega)$ 以 $\Omega_s$ 为周期的延拓：

```
原频谱:        /\              (带宽为 [-Ω_h, Ω_h])
              /  \
        -----/    \-----
            Ω=0

采样后:    /\     /\     /\    (每隔 Ω_s 重复)
          /  \   /  \   /  \
    -----/    \-/-----\-/-----\-----
       -Ω_s    0     Ω_s     2Ω_s
```

要能从 $\hat{X}_a(j\Omega)$ **无失真地恢复**出 $X_a(j\Omega)$，各个周期延拓的"副本"之间不能有**混叠（aliasing）**。条件：

$$\Omega_s - \Omega_h \geqslant \Omega_h$$

即：

$$\boxed{\Omega_s \geqslant 2\Omega_h \quad \text{或} \quad f_s \geqslant 2f_h}$$

这就是**奈奎斯特采样定理**：采样频率至少为信号最高频率的两倍。

> **"混叠"的形象理解**：如果采样不够密（$\Omega_s < 2\Omega_h$），相邻的频谱副本会相互重叠，就像把两页透明胶片叠在一起看——你分不清哪些频率是原来的，哪些是"拷贝"过来的。

#### 数字频率 $\omega$ 与模拟角频率 $\Omega$ 的关系

$$\boxed{\omega = \Omega T = \frac{\Omega}{f_s}}$$

- $\Omega$：模拟角频率，单位 rad/s
- $\omega$：数字频率，单位 rad（无量纲）
- $T$：采样间隔

当 $\Omega = \Omega_s = 2\pi/T$ 时，$\omega = \Omega_s T = 2\pi$。所以数字频率的周期是 $2\pi$——这与序列频谱以 $2\pi$ 为周期完全吻合。

### 1.5.2 由采样信号恢复模拟信号

#### 理想低通滤波

从周期延拓的频谱中"切"出 $[-\Omega_s/2, \Omega_s/2]$ 这一段，用一个理想低通滤波器：

$$G(j\Omega) = \begin{cases} T & |\Omega| < \Omega_s/2 \\ 0 & |\Omega| \geqslant \Omega_s/2 \end{cases}$$

#### 时域插值公式 —— 本章第二个核心频域公式

$$\boxed{x_a(t) = \sum_{n=-\infty}^{\infty} x_a(nT) \frac{\sin[\pi(t - nT)/T]}{\pi(t - nT)/T}} \tag{5}$$

> **公式解读**：恢复后的模拟信号 = 所有采样值 $x_a(nT)$ 分别乘以 $\operatorname{sinc}$ 函数（$\frac{\sin x}{x}$），然后叠加。$\operatorname{sinc}$ 函数在采样点 $nT$ 处取值为 1，在其他采样点处取值为 0——这保证了恢复后的曲线精确经过每个采样点。

#### 插值函数的性质

定义插值函数（$\operatorname{sinc}$ 函数）：

$$\operatorname{sinc}\!\left(\frac{t}{T}\right) = \frac{\sin(\pi t/T)}{\pi t/T}$$

性质：
- $\operatorname{sinc}(0) = 1$（通过极限 $\lim_{x\to 0}\sin x / x = 1$ 得到）
- 在 $t = mT$ 且 $m \neq 0$ 处，$\operatorname{sinc}(m) = 0$（因为 $\sin(m\pi) = 0$）

> **这就是插值公式的"魔法"所在**：对于某一采样点 $t = nT$，只有第 $n$ 项的 sinc 函数贡献值为 $x_a(nT) \cdot 1$，其余所有项在该点都取值为零——所以恢复曲线精确通过每一个采样点。采样点之间的值则由所有 sinc 函数的"尾巴"共同决定。
