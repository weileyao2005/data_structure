# 6.4 均匀平面波对理想导体平面的斜入射

均匀平面波对理想导体表面的斜入射同样可分为垂直极化波和平行极化波两种情况进行讨论。

## 6.4.1 垂直极化波对理想导体表面的斜入射

如图 6.4.1 所示，媒质 1 为无损耗介质，媒质 2 为理想导体。对于理想导体，$\eta_2 = 0$，利用前面得到的垂直极化波入射的菲涅尔公式(6.3.24)和式(6.3.25)，可得
$$\Gamma_{\perp} = -1, \tau_{\perp} = 0$$
入射波的电场和磁场
$$\boldsymbol{E}_i = \mathbf{e}_y E_m e^{-jk(x\sin\theta_i + z\cos\theta_i)} \tag{6.4.1}$$
$$\boldsymbol{H}_i = (-\mathbf{e}_x \cos\theta_i + \mathbf{e}_z \sin\theta_i) \frac{E_m}{\eta} e^{-jk(x\sin\theta_i + z\cos\theta_i)} \tag{6.4.2}$$


**图 6.4.1** 垂直极化波对理想导体平面的斜入射

反射波的电场和磁场
$$\boldsymbol{E}_r = -\mathbf{e}_y E_m e^{-jk(x\sin\theta_i - z\cos\theta_i)} \tag{6.4.3}$$
$$\boldsymbol{H}_r = (-\mathbf{e}_x \cos\theta_i - \mathbf{e}_z \sin\theta_i) \frac{E_m}{\eta} e^{-jk(x\sin\theta_i - z\cos\theta_i)} \tag{6.4.4}$$
媒质 1 中的合成波的电场和磁场为
$$\boldsymbol{E}_1 = \boldsymbol{E}_i + \boldsymbol{E}_r = -\mathbf{e}_y j 2 E_m \sin(kz \cos \theta_i) e^{-jkx \sin \theta_i} \tag{6.4.5}$$
$$\boldsymbol{H}_1 = [-\mathbf{e}_x \cos \theta_i \cos(kz \cos \theta_i) - \mathbf{e}_z j \sin \theta_i \sin(kz \cos \theta_i)] \frac{2E_m}{\eta} e^{-jkx \sin \theta_i} \tag{6.4.6}$$
由此可见，垂直极化波斜入射到理想导体表面时，有如下特点：
(1) 合成波沿平行于分界面的方向（即 $x$ 方向）传播，其相速为
$$v_{px} = \frac{\omega}{k_{ix}} = \frac{v_p}{\sin \theta_i}$$
(2) 合成波振幅在垂直于导体表面的方向（即 $z$ 方向）上呈驻波分布，而且合成波电场在 $z = -\frac{n\pi}{k \cos \theta_i} (n = 0, 1, 2, \dots)$ 处为 0；
(3) 合成波是非均匀平面波；
(4) 在合成波的传播方向（即 $x$ 方向）上不存在电场分量，但存在磁场分量，是横电波（TE波）。

**例 6.4.1** 角频率为 $\omega$ 的均匀平面波由空气向理想导体斜入射，入射角为 $\theta_i$，电场矢量垂直于入射面。求：(1) 导体表面上的感应电流密度；(2) 合成波在空气中的平均坡印廷矢量。
解：(1) 由题意可知，该问题为垂直极化入射。设 $z=0$ 为理想导体表面，则入射波波矢量
$$\boldsymbol{k}_i = k \mathbf{e}_i = \mathbf{e}_x k \sin \theta_i + \mathbf{e}_z k \cos \theta_i$$
入射波电场为
$$\boldsymbol{E}_i = \mathbf{e}_y E_m e^{-jk(x\sin \theta_i + z\cos \theta_i)}$$
对于垂直极化入射，$\Gamma_{\perp} = -1$，所以反射波电场为
$$\boldsymbol{E}_r = -\mathbf{e}_y E_m e^{-jk(x\sin \theta_i - z\cos \theta_i)}$$
式中 $E_m$ 为入射波幅值，$k = \omega \sqrt{\mu_0 \varepsilon_0}$ 为波数。
由
$$\boldsymbol{H} = \frac{1}{\eta} \mathbf{e}_n \times \boldsymbol{E} = \frac{k}{\omega \mu} \times \boldsymbol{E}$$
得
$$\boldsymbol{H}_i = (-\mathbf{e}_x \cos \theta_i + \mathbf{e}_z \sin \theta_i) \frac{E_m}{\eta_0} e^{-jk(x\sin \theta_i + z\cos \theta_i)}$$
$$\boldsymbol{H}_r = (-\mathbf{e}_x \cos \theta_i - \mathbf{e}_z \sin \theta_i) \frac{E_m}{\eta_0} e^{-jk(x\sin \theta_i - z\cos \theta_i)}$$
空气中合成波的磁场为
$$\boldsymbol{H}_1 = \boldsymbol{H}_i + \boldsymbol{H}_r$$
在 $z=0$ 处
$$\boldsymbol{H}_1 = (\boldsymbol{H}_i + \boldsymbol{H}_r)|_{z=0} = -\mathbf{e}_x \frac{2E_m}{\eta_0} \cos \theta_i e^{-jkx \sin \theta_i}$$
所以导体表面上的感应电流密度为
$$\boldsymbol{J}_s = \mathbf{e}_n \times \boldsymbol{H}_1|_{z=0} = (-\mathbf{e}_z) \times (-\mathbf{e}_x) \frac{2E_m \cos \theta_i}{\eta_0} e^{-jkx \sin \theta_i} = \mathbf{e}_y \frac{E_m}{60\pi} \cos \theta_i e^{-jkx \sin \theta_i}$$
(2) 因为
$$\boldsymbol{E}_r = -\mathbf{e}_y E_m e^{-jk(x\sin \theta_i - z\cos \theta_i)}$$
故合成波在空气中的平均坡印廷矢量为
$$\boldsymbol{S}_{av} = \frac{1}{2} \text{Re}[\boldsymbol{E}_1 \times \boldsymbol{H}_1^*] = \frac{1}{2} \text{Re}[(\boldsymbol{E}_i + \boldsymbol{E}_r) \times (\boldsymbol{H}_i + \boldsymbol{H}_r)^*] = \mathbf{e}_x \frac{2E_m^2}{\eta_0} \sin \theta_i \sin^2(kz \cos \theta_i)$$

## 6.4.2 平行极化波对理想导体表面的斜入射

如图 6.4.2 所示，利用前面得到的平行极化波入射的菲涅尔公式(6.3.39)和式(6.3.40)，可得
$$\Gamma_{//} = 1, \tau_{//} = 0$$


**图 6.4.2** 平行极化波对理想导体平面的斜入射

入射波的电场和磁场
$$\boldsymbol{H}_i = \mathbf{e}_y \frac{E_m}{\eta} e^{-jk(x\sin \theta_i + z\cos \theta_i)} \tag{6.4.7}$$
$$\boldsymbol{E}_i = (\mathbf{e}_x \cos \theta_i - \mathbf{e}_z \sin \theta_i) E_m e^{-jk(x\sin \theta_i + z\cos \theta_i)} \tag{6.4.8}$$
反射波的电场和磁场
$$\boldsymbol{H}_r = \mathbf{e}_y \frac{E_m}{\eta} e^{-jk(x\sin \theta_i - z\cos \theta_i)} \tag{6.4.9}$$
$$\boldsymbol{E}_r = (-\mathbf{e}_x \cos \theta_i - \mathbf{e}_z \sin \theta_i) E_m e^{-jk(x\sin \theta_i - z\cos \theta_i)} \tag{6.4.10}$$
媒质 1 中的合成波场量
$$\boldsymbol{H}_1 = \boldsymbol{H}_i + \boldsymbol{H}_r = \mathbf{e}_y 2 \frac{E_m}{\eta} \cos(kz \cos \theta_i) e^{-jkx \sin \theta_i} \tag{6.4.11}$$
$$\boldsymbol{E}_1 = -[\mathbf{e}_x j \cos \theta_i \sin(kz \cos \theta_i) + \mathbf{e}_z \sin \theta_i \cos(kz \cos \theta_i)] 2 E_m e^{-jkx \sin \theta_i} \tag{6.4.12}$$

由此可见，平行极化波斜入射到理想导体表面时，有如下特点：
（1）合成波沿平行于分界面的方向（即 $x$ 方向）传播，其相速为
$$v_{\text{p}x} = \frac{\omega}{k_{\text{i}x}} = \frac{v_{\text{p}}}{\sin\theta_{\text{i}}}$$
（2）合成波的振幅在垂直于导体表面的方向（即 $z$ 方向上呈驻波分布，而且合成波磁场在 $z=-\frac{n\pi}{k\cos\theta_{\text{i}}}$ $(n=0,1,2,\cdots)$ 处达到最大值；
（3）合成波是非均匀平面波；
（4）在波的传播方向（即 $x$ 方向）上不存在磁场分量，但存在电场分量，是横磁波（TM 波）。
**例 6.4.2** 已知空气中磁场强度为 $\boldsymbol{H}_{\text{i}} = -\boldsymbol{e}_y e^{-j\sqrt{2}\pi(x+z)}$ A/m 的均匀平面波，向位于 $z=0$ 处的理想导体斜入射。求：（1）入射角；（2）入射波电场；（3）反射波电场和磁场；（4）合成波的电场和磁场；（5）导体表面上的感应电流密度和电荷密度。
**解：**（1）由题意可知，$k_{\text{i}x} = k_{\text{i}z} = \sqrt{2} \pi$，所以
$$\boldsymbol{k}_{\text{i}} = \boldsymbol{e}_x k_{\text{i}x} + \boldsymbol{e}_z k_{\text{i}z} = (\boldsymbol{e}_x + \boldsymbol{e}_z) \sqrt{2} \pi, \quad k = |\boldsymbol{k}_{\text{i}}| = 2\pi$$
故入射角为
$$\theta_{\text{i}} = \arctan \frac{k_{\text{i}x}}{k_{\text{i}z}} = \frac{\pi}{4}$$
（2）入射波电场为
$$\boldsymbol{E}_{\text{i}} = \eta_0 \boldsymbol{H}_{\text{i}} \times \boldsymbol{e}_{\text{i}} = \frac{\eta_0}{k} \boldsymbol{H}_{\text{i}} \times \boldsymbol{k}_{\text{i}} = (-\boldsymbol{e}_x + \boldsymbol{e}_z) \frac{120\pi}{\sqrt{2}} e^{-j\sqrt{2}\pi(x+z)} \quad \text{V/m}$$
（3）反射波矢量为
$$\boldsymbol{k}_{\text{r}} = \boldsymbol{e}_x k_{\text{i}x} - \boldsymbol{e}_z k_{\text{i}z} = (\boldsymbol{e}_x - \boldsymbol{e}_z) \sqrt{2} \pi$$
由于是平行极化入射 $\varGamma_{//}=1$，故反射波磁场和电场分别为
$$\boldsymbol{H}_{\text{r}} = -\boldsymbol{e}_y e^{-j\sqrt{2}\pi(x-z)} \quad \text{A/m}$$
$$\boldsymbol{E}_{\text{r}} = \eta_0 \boldsymbol{H}_{\text{r}} \times \boldsymbol{e}_{\text{r}} = \frac{\eta_0}{k} \boldsymbol{H}_{\text{r}} \times \boldsymbol{k}_{\text{r}} = (\boldsymbol{e}_x + \boldsymbol{e}_z) \frac{120\pi}{\sqrt{2}} e^{-j\sqrt{2}\pi(x-z)} \quad \text{V/m}$$
（4）合成波的电场和磁场分别为
$$\boldsymbol{E}_{1} = \boldsymbol{E}_{\text{i}} + \boldsymbol{E}_{\text{r}} = [\boldsymbol{e}_x (e^{j\sqrt{2}\pi z} - e^{-j\sqrt{2}\pi z}) + \boldsymbol{e}_z (e^{j\sqrt{2}\pi z} + e^{-j\sqrt{2}\pi z})] \frac{120\pi}{\sqrt{2}} e^{-j\sqrt{2}\pi x}$$
$$= [\boldsymbol{e}_x j\sin(\sqrt{2}\pi z) + \boldsymbol{e}_z \cos(\sqrt{2}\pi z)] 120\sqrt{2}\pi e^{-j\sqrt{2}\pi x} \quad \text{V/m}$$
$$\boldsymbol{H}_{1} = \boldsymbol{H}_{\text{i}} + \boldsymbol{H}_{\text{r}} = -\boldsymbol{e}_y (e^{j\sqrt{2}\pi z} + e^{-j\sqrt{2}\pi z})] e^{-j\sqrt{2}\pi x} = -\boldsymbol{e}_y 2\cos(\sqrt{2}\pi z) e^{-j\sqrt{2}\pi x} \quad \text{A/m}$$
（5）导体表面上的感应电流密度和电荷密度分别为
$$\boldsymbol{J}_{S} = \boldsymbol{e}_{\text{n}} \times \boldsymbol{H}_{1} \big|_{z=0} = (-\boldsymbol{e}_z) \times (-\boldsymbol{e}_y) 2 e^{-j\sqrt{2}\pi x} = -\boldsymbol{e}_x 2 e^{-j\sqrt{2}\pi x} \quad \text{A/m}$$
$$\rho_{S} = \varepsilon_0 \boldsymbol{e}_{\text{n}} \cdot \boldsymbol{E}_{1} \big|_{z=0} = -\varepsilon_0 \boldsymbol{e}_z \cdot \boldsymbol{E}_{1} \big|_{z=0} = -120\sqrt{2}\pi \varepsilon_0 e^{-j\sqrt{2}\pi x} \quad \text{C/m}^2$$
**例 6.4.3** 均匀平面波从 $\mu=\mu_0$、$\varepsilon=2.25\varepsilon_0$ 的理想介质中斜入射到位于 $x=0$ 处的无限大理想导体平面上，如图 6.4.3 所示。已知入射波电场强度
$$\boldsymbol{E}_{\text{i}}(x,y) = (-\boldsymbol{e}_x + \boldsymbol{e}_y \sqrt{3} + \boldsymbol{e}_z j2) e^{-j\pi(\sqrt{3}x+y)} \quad \text{V/m}$$

**图 6.4.3** 平面波对理想导体表面的斜入射
试求：（1）频率 $f$、波长 $\lambda$ 和磁场强度 $\boldsymbol{H}_{\text{i}}(x,y)$；（2）入射波的极化特性；（3）反射波电场强度 $\boldsymbol{E}_{\text{r}}(x,y)$ 和磁场强度 $\boldsymbol{H}_{\text{r}}(x,y)$；（4）理想导体表面上的感应电流密度 $\boldsymbol{J}_{S}(y)$ 和电荷密度 $\rho_{S}(y)$。
**解：** 由题意可知入射波的波矢量
$$\boldsymbol{k}_{\text{i}} = \boldsymbol{e}_x \sqrt{3} \pi + \boldsymbol{e}_y \pi$$
所以
$$k_{\text{i}} = \sqrt{k_{\text{i}x}^2 + k_{\text{i}y}^2} = 2\pi$$
$$\lambda = \frac{2\pi}{k_{\text{i}}} = 1 \text{ m}$$
$$f = \frac{c}{\lambda \sqrt{\varepsilon_{\text{r}}}} = 2 \times 10^8 \text{ Hz}$$
$$\boldsymbol{H}_{\text{i}}(x,y) = \frac{1}{\eta} \boldsymbol{e}_{\text{i}} \times \boldsymbol{E}_{\text{i}}(x,y) = \frac{1}{80\pi} (\boldsymbol{e}_x j - \boldsymbol{e}_y j\sqrt{3} + \boldsymbol{e}_z 2) e^{-j\pi(\sqrt{3}x+y)} \text{ A/m}$$
（2）将入射波电场表示为
$$\boldsymbol{E}_{\text{i}}(x,y) = (\boldsymbol{E}_{\text{mR}} + j\boldsymbol{E}_{\text{mI}}) e^{-j\boldsymbol{k}_{\text{i}} \cdot \boldsymbol{r}}$$
其中
$$\boldsymbol{E}_{\text{mR}} = -\boldsymbol{e}_x + \boldsymbol{e}_y \sqrt{3} \quad \boldsymbol{E}_{\text{mI}} = \boldsymbol{e}_z 2$$
因为
$$(\boldsymbol{E}_{\text{mI}} \times \boldsymbol{E}_{\text{mR}}) \cdot \boldsymbol{k} = [\boldsymbol{e}_z 2 \times (-\boldsymbol{e}_x + \boldsymbol{e}_y \sqrt{3})] \cdot (\boldsymbol{e}_x \sqrt{3} \pi + \boldsymbol{e}_y) < 0$$
$$|\boldsymbol{E}_{\text{mR}}| = |\boldsymbol{E}_{\text{mI}}| = 2$$
故入射波为左旋圆极化波；
（3）由边界面所在位置 $(x=0)$ 和入射波波矢量的表示式 $(\boldsymbol{k}_{\text{i}} = \boldsymbol{e}_x \sqrt{3} \pi + \boldsymbol{e}_y \pi)$ 可知，该斜入射问题的入射面为 $xy$ 平面。而入射波电场既有垂直极化分量，又有平行极化分量，可以直接根据理想导体表面电场和磁场满足的边界条件以及平面波对理想导体斜入射时其反射系数 $|\varGamma_{\perp}| = |\varGamma_{//}| = 1$ 来确定反射波。
因为理想导体表面电场切向分量为零，法向分量不为零，所以反射波电场与入射波电场的切向（$\boldsymbol{e}_y$ 和 $\boldsymbol{e}_z$）分量应等值反向，又因为反射系数 $|\varGamma_{\perp}| = |\varGamma_{//}| = 1$，所以反射波电场与入射波电场的法向（$\boldsymbol{e}_x$）分量应等值同向。于是得反射波电场
$$\boldsymbol{E}_{\text{r}}(x,y) = (-\boldsymbol{e}_x - \boldsymbol{e}_y \sqrt{3} - \boldsymbol{e}_z j2) e^{-j\pi(-\sqrt{3}x+y)} \text{ V/m}$$
式中
$$\boldsymbol{k}_{\text{r}} = -\boldsymbol{e}_x \sqrt{3} \pi + \boldsymbol{e}_y \pi$$
为反射波的波矢量。反射波的磁场为
$$\boldsymbol{H}_{\text{r}}(x,y) = \frac{1}{\eta} \frac{\boldsymbol{k}_{\text{r}}}{k_{\text{r}}} \times \boldsymbol{E}_{\text{r}}$$
$$= \frac{1}{80\pi} (-\boldsymbol{e}_x j - \boldsymbol{e}_y j\sqrt{3} + \boldsymbol{e}_z 2) e^{-j\pi(-\sqrt{3}x+y)} \text{ A/m}$$
（4）导体表面上的感应电流面密度和电荷面密度分别为
$$\boldsymbol{J}_{S} = \boldsymbol{e}_{\text{n}} \times \boldsymbol{H}_{1} \big|_{x=0} = -\boldsymbol{e}_x \times (\boldsymbol{H}_{\text{i}} + \boldsymbol{H}_{\text{r}}) \big|_{x=0} = \frac{1}{40\pi} (\boldsymbol{e}_y 2 + \boldsymbol{e}_z j\sqrt{3}) e^{-j\pi y} \text{ A/m}$$
$$\rho_{S} = \varepsilon \boldsymbol{e}_{\text{n}} \cdot \boldsymbol{E}_{1} \big|_{x=0} = -\varepsilon \boldsymbol{e}_x \cdot (\boldsymbol{E}_{\text{i}} + \boldsymbol{E}_{\text{r}}) \big|_{x=0} = 4.5 \varepsilon_0 e^{-j\pi y} \text{ C/m}^2$$
